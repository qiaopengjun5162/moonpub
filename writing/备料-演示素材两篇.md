## 为什么这么分

原来 4 篇草稿（10 排版 / 11 封面 / 12 推草稿 / 15 报错）停在你手动发表那一步。
按你的要求压成 **2 篇**，素材改用演示资料——它的图现成、叙事已经讲清了项目，符合"图多字少"。

## 篇 A · 讲清项目

**建议标题**（按 BACKLOG 硬规矩：MoonPub 前置 + 大白话收益，不用"发版/CI"黑话）：

- 首选：`MoonPub 写完就直接排好版，最后那一下留给你`
- 备选：`MoonPub 省掉的不是写作，是写完后的搬运`

**frontmatter 建议**：`theme: mist`、`cover_style: geek-black`（教程系列既定搭配，别用 blueprint 封面）、
`cover_title` ≤10 字、`cover_subtitle` ≤34 字、`cover_tag: MOONPUB · 上手教程`。

### 骨架与图位（每节一句话要点，正文你写）

1. **开头 · 先看成品**（`cover-fade.png` 或 `preview.png`）
   → 一句话定位：Markdown 进、公众号草稿出；你写、它干活、你发表。

2. **它替你做了什么**（无图，用文字列表）
   → 排版 / 封面 / 图片上传 / 后台四项设置 / 推草稿；全部本地跑，凭证不出电脑。

3. **省的不是创作时间**（讲稿 P3 的数字）
   → 手动 30–40 分钟 vs 用它约 3 分钟；更值钱的是十篇文章样式永远一致。

4. **换样子只改一个词**（`themes.png`）
   → 同一段字四种外观；技术文 / 通用文各给一个保底推荐。

5. **缩到拇指盖才是真考验**（`cover-thumbs.png`）
   → 纯白封面糊成一片，深色和渐变站得住。这条经验对所有写公众号的人都成立，跟用不用工具无关。

6. **一条命令做完六件事**（`push.png`）
   → 重点：它不是点完就算，会重载编辑器读后台真实状态；发表那下仍留给你。

7. **凭什么信 / 边界**（无图，用数字 + 短列表）
   → 1090 测试、行覆盖 85.2%、五平台 sha256、每周依赖扫描（截至 2026-11-28，讲稿已对齐）。
   → 边界照念：只做公众号 / 依赖后台界面 / 登录态会过期 / 命令行有门槛 / Beta。

## 篇 B · 跟着图走一遍

**建议标题**：

- 首选：`MoonPub 从安装到草稿箱，跟着这几张图走`
- 备选：`MoonPub 上手，四条命令看到成品`

**frontmatter**：同 A 篇。

### 骨架与图位

1. **安装**（`install.png`）
   → 解压 + 移到 PATH；`--version` 出号就算装好。

2. **建配置、建文章**（`initnew.png`）
   → `init --yes` / `new "标题"`；每步末尾它打印下一条命令。

3. **你写的就长这样**（`source.png`）
   → 抬头三行 title/digest/theme；`:::intro` / `:::summary` 两个块；不用学 Markdown。

4. **一键出成品**（`preview.png`）
   → `render` 产出 HTML + draft.json；`preview` 浏览器打开；断网也能看。

5. **换样子**（`themes.png`）
   → 改 `theme` 一个词，重新 render；名字拼错会报错不兜底。

6. **封面一句话生成**（`cover-styles.png`）
   → `--style` 换风格；三个字段 cover_title / subtitle / tag。

7. **推草稿**（`push.png`）
   → cookie 扫码一次（约三天过期）；`push --render`；四项复核落库。

8. **目录里留下什么**（`tree.png`）
   → 只有 .md 是源文件，其余生成物已 gitignore；`.media_id` 别删。

9. **卡住了**（无图，报错表压到 5 行内）
   → 会话过期→`login`；产物过期→`--render`；图找不到→`preflight`；主题名拼错→查清单；标题超 64 字→砍短。
   → 兜底两句：`doctor` 查配置，`status` 看本地状态。

## 你写正文时的三条提醒

1. **每节控制在 3–5 句**，图说清楚的就不再用文字重复——这是"图多字少"的关键。
2. **图注写"这张图证明了什么"**，不写"截图"；终端输出用代码块，别截成图（STYLE.md 硬规矩）。
3. **数字带测量时间**：1090 / 85.2% / v0.4.32 都写"截至 2026-11-28"，讲稿已对齐，别再手改。

## 成稿后（等你写完我再做）

骨架文件写好正文后，跑这五项，全过才算成稿：

```bash
moonpub render writing/articles/<文件>.md
moonpub layout-audit writing/articles/<文件>.html
moonpub preflight writing/articles/<文件>.md
moonpub cover writing/articles/<文件>.md --style geek-black --screenshot
grep -o '](\.\./assets/[^)]*)' writing/articles/<文件>.md
```

再推草稿（渲染 + 上传图 + 四项设置复核 + 手机预览），最终发表你手动点。
