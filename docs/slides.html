You write an article in Markdown. To publish on WeChat, you need to:

📝 Convert Markdown to WeChat HTMLManual

Key Features

🎨 Cover Generator

6 built-in styles. Or skip entirely and use your own image via thumb_media_id config.

🧱 Block Templates

12 WeChat-optimized layout blocks. book-info, callout, steps, summary, quote-card...

🤖 Headless CDP

Auto-configure draft settings via Chrome DevTools. Scan QR once, then fully automated.

🔍 De-AI Pipeline

6-stage rule pipeline strips AI writing patterns. No LLM needed.

📡 Radar

Platform trend tracking. Scrape hot topics, generate title suggestions.

🐳 Docker Ready

Multi-stage build with Chromium pre-installed. Run anywhere.

How to Use

1. Install

cargo install --git
https://github.com/
qiaopengjun5162/moonpub

Or: Docker build

2. Configure

WECHAT_APPID=wx***
WECHAT_SECRET=***

moonpub init

3. Write & Ship

moonpub ship
  article.md
  --style gradient

Ship: What Happens

StepWhat it doesTime
coverGenerate HTML cover from frontmatter title/digest/author10ms
renderMarkdown + blocks → WeChat HTML with inline CSS50ms
pushUpload HTML + images to WeChat draft via API2s
configureChrome headless: set originality, tips, comments, source30s
exportSync to Zola blog (YAML→TOML frontmatter)10ms

Total: ~35 seconds from Markdown to configured WeChat draft.
