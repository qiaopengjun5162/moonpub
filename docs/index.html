MoonPub

Markdown 写完，一行命令推进到微信后台可确认发布。
封面、排版、原创声明、留言、赞赏 — 本地辅助完成。

RustmacOSLinuxWindowsMIT 
$ moonpub ship article.md

零 AI 依赖 — 纯 Rust — 完全离线

四步发布副驾驶

1

写 Markdown

---
title: 我为什么开始每天读书
digest: 一个普通人的阅读实验
---

:::intro
去年这个时候，我还在刷短视频。
:::

正文……
2

预览

moonpub render article.md
moonpub preview article.md
3

推到可确认发布

moonpub ship article.md
辅助完成：封面截图 → 排版渲染 → API 推送 → 浏览器配置 → 博客导出
4

搞定

文章在微信草稿箱里，原创声明✅ 赞赏✅ 留言✅ 创作来源✅ 预览已发送。检查无误后手动点"发表"。

AI 辅助写作

moonpub write "想法"从一句话生成完整文章
moonpub expand notes.md读书笔记展开成文章
moonpub polish draft.mdAI 润色 + 去 AI 味
moonpub ship draft.md --ai润色 + 发布副驾驶

默认读取 DEEPSEEK_API_KEY；切到 OpenAI 时读取 OPENAI_API_KEY

核心能力

🎨

自动排版

17 种 Block 模板（intro/callout/key-points/scene-card/closing-card…），20 套正文主题，inline CSS 100% 微信兼容。

🤖

浏览器自动化

headless Chrome 辅助配置原创声明、赞赏、留言、创作来源、预览。扫码登录一次，最终发布仍由你确认。

🖼

封面生成

10 套封面风格（dark/clean/minimal/warm/serif/gradient/literary/ink/sunset/forest），自动截图上传微信。

✍️

去 AI 味

6 阶段规则引擎，去掉套话、排比、AI 词汇。AI 写 + 去 AI 味 = 自然文章。

📦

博客同步

自动导出 Zola 博客（YAML→TOML），一篇文章同时发公众号和个人博客。

🔒

零依赖离线

纯 Rust，仅 ureq(HTTP) + chromiumoxide(CDP)。核心渲染不依赖第三方 API；AI 写作仅在你显式使用并配置 provider 时调用。

安装

macOS Apple Silicon

curl -L https://github.com/qiaopengjun5162/moonpub/releases/download/v0.4.1/moonpub-macos-arm64.tar.gz | tar xz && sudo mv moonpub /usr/local/bin/

macOS Intel

curl -L https://github.com/qiaopengjun5162/moonpub/releases/download/v0.4.1/moonpub-macos-amd64.tar.gz | tar xz && sudo mv moonpub /usr/local/bin/

Linux x86_64

curl -L https://github.com/qiaopengjun5162/moonpub/releases/download/v0.4.1/moonpub-linux-amd64.tar.gz | tar xz && sudo mv moonpub /usr/local/bin/

Linux ARM64

curl -L https://github.com/qiaopengjun5162/moonpub/releases/download/v0.4.1/moonpub-linux-arm64.tar.gz | tar xz && sudo mv moonpub /usr/local/bin/

Cargo

cargo install --git https://github.com/qiaopengjun5162/moonpub

当前公开可下载 release 为 v0.4.1。Windows 用户从 Releases 下载 zip；Homebrew tap 尚未发布

所有命令

moonpub new "标题"创建文章模板
moonpub write "想法"AI 生成文章
moonpub expand article.md笔记展开成文章
moonpub polish article.mdAI 润色
moonpub render article.mdMarkdown → HTML
moonpub preview article.md浏览器预览
moonpub push article.md推送到微信草稿
moonpub ship article.md发布副驾驶全流程
moonpub configure自动配置草稿设置
moonpub export article.md导出博客
moonpub humanize article.md去 AI 味
moonpub cover article.md生成封面
moonpub init创建配置文件
moonpub login微信扫码登录
moonpub status文章流水线状态
