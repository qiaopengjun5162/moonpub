# writing/ —— 项目过程素材库

这里不放代码，只放**做这件事的过程**。

代码在 `src/`，产品说明在 `docs/`，进度在 `PROGRESS.md`。而这里回答一个别的地方都没有回答的问题：

> 这个项目是怎么一步一步长出来的，中间坏了什么，怎么修好的，凭什么说它是真的。

## 为什么要有这个目录

技术文章最容易犯的错，是**事后凭记忆重写一遍**。回忆会自动美化：把试错的二十次压成一句"最终选择了方案 B"，把三小时的连续攻坚写成一段优雅的架构说明。读者看完会觉得你很聪明，但学不到任何东西，因为他看不到你卡住的那一刻。

这个仓库有 484 次提交，其中 163 次是修 bug。这些提交本身就是最诚实的记录——它们按时间排好了，改不了，也没法美化。所以这里的做法是：**以 git log 为骨架，把每一次真实的失败和修复钉在时间轴上**。

## 三条铁律

**一、只写发生过的事。** 每个结论后面必须能指到一个提交号、一段命令输出、一张截图或一行日志。指不到的，不写。

**二、记录失败，比记录成功重要。** 一次 `revert`、一次 `浏览器永不关闭`、一次 CI 红了三遍，价值大于十个 `feat:`。因为读者能复用的是你踩坑的路径，不是你的功能列表。

**三、数字要能复算。** 说"覆盖 74%"就得给出跑出这个数字的命令；说"484 次提交"就得给出 `git log --oneline | wc -l`。读者能自己跑一遍验证，文章才立得住。

## 一次操作的最小记录

不用写得漂亮，但六件事缺一不可：

| 要素 | 回答什么 | 例子 |
| --- | --- | --- |
| 意图 | 本来想干什么 | 想给微信客户端加个可注入的出口 |
| 输入 | 我给了什么 | 现有 `WechatClient` 代码、一条覆盖率报告 |
| 输出 | 实际发生了什么 | 编译过了，但 18 个测试里有 3 个 panic |
| 解释 | 为什么是这样 | 硬编码域名，测试只能拿到字符串，拿不到 HTTP |
| 问题 | 卡在哪 | 本地 127.0.0.1 也会走 `HTTPS_PROXY`，请求被打成 502 |
| 证据 | 凭什么这么说 | 提交 `c1c1286`、`curl` 输出、`llvm-cov` 报告数字 |

模板在 [`operations/TEMPLATE.md`](operations/TEMPLATE.md)。

## 记录怎么变成文章

三层，从下往上：

```text
operations/  一次操作的原始记录（脏的、带报错的、带截图的）
     ↓  提炼
chronicle/   一个阶段的骨架（按时间排，带真实数字）
     ↓  叙事
articles/    给读者看的成稿（有冲突、有转折、有结论）
```

写文章时不要去翻聊天记录，去翻这三层。一篇好文章的骨架通常是：

**具体痛点 → 第一次尝试 → 失败 → 为什么失败 → 换方案 → 又失败 → 找到根因 → 修复 → 留下什么教训**

这个结构不需要编，`git log` 里本来就有。

## 成稿自检

文章写完后，用项目自己跑一遍。这不是仪式，它能真的抓出问题：frontmatter 键写错、摘要超 120 字被截断、排版有微信不兼容的结构。

```bash
# 在临时目录里渲染，不污染仓库
mkdir -p /tmp/wtest/Articles/drafts
cp "writing/articles/01-第一个提交4967行.md" /tmp/wtest/Articles/drafts/
cargo run --quiet -- --articles /tmp/wtest render "Articles/drafts/01-第一个提交4967行.md"

# 排版质量门
cargo run --quiet -- --articles /tmp/wtest layout-audit \
  "/tmp/wtest/Articles/drafts/01-第一个提交4967行.html"
```

`layout-audit` 报 `status: passed` 才算过。它只检查本地 HTML 的微信兼容性，不碰网络。
骨架、标题、图片的硬性要求见 [`STYLE.md`](STYLE.md)。

## 红线

- 不写真实 `AppSecret`、`access_token`、cookie、二维码、手机号、微信号、后台敏感 URL。
- 不把"代码写了"写成"验证过了"。没跑过的就是没跑过，写清楚。
- 不把别人的成果说成自己的。参考过的项目按 `docs/*_REFERENCE_ZH.md` 的惯例注明。
- 截图提交前必须自己看一遍，确认没有露出账号信息。

脱敏细节见 [`PROTOCOL.md`](PROTOCOL.md) 最后一节。
